# Nexora Güvenlik Politikası

Nexora platformunun güvenliği bizim için en yüksek önceliktir.

## Desteklenen Sürümler
Şu anda yalnızca en güncel ana dal (`master`) güvenlik yamaları ve güncellemeleri ile desteklenmektedir.

## Güvenlik Açığı Bildirimi
Platformumuzda potansiyel bir güvenlik zafiyeti tespit ettiyseniz:
1. Lütfen açığı GitHub Issues üzerinden herkese açık olarak **paylaşmayınız**.
2. GitHub üzerindeki **Private Vulnerability Reporting** sekmesini kullanarak doğrudan ve gizli olarak bildiriniz.
3. Bildiriminiz en geç 48 saat içerisinde değerlendirilecek ve gerekli düzeltmeler ivedilikle uygulanacaktır.
