Mimari nasıl korundu?

Domain: sipariş geçişi ve kupon indirim kuralı; framework, veri erişimi ve HTTP bağımlılığı yok.

Application: feature handler/validator/DTO düzeni; transaction ve token koruması gerekli portlarla ifade edilir. Checkout ve quote aynı feature fiyat hesabını kullanır.

Persistence / Infrastructure: PostgreSQL advisory lock, xmin, indeks/check ve migration; Redis, outbox, SMTP, dosya codec/cleanup adaptörleri.

API / Frontend: controller kullanıcı kimliğini claim'den alıp MediatR'a iletir; React mevcut Query/Context düzeninde kaldı. Gereksiz repository, genel base handler veya yeni framework katmanı eklenmedi.

Parent SKU ve varyantlar mevcut bağımsız fiyat/stok politikasıyla satın alınabilir; varyant mecburiyeti gibi yeni bir domain kararı sessizce eklenmedi. Bu davranış üç varyant regresyonuyla belgelendi.
