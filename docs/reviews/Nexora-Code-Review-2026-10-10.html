Rolü kaldırılan yöneticinin eski JWT’si yeniden yetkili oluyor

Admin rolü kaldırılınca kullanıcıya revoke bayrağı konuyor. Kullanıcı yeni Customer rolüyle başarılı giriş yapınca Login bu ortak bayrağı siliyor. Sakladığı eski JWT’nin Admin claim’i hâlâ geçerli; API güncel rolü veya token sürümünü karşılaştırmıyor.

Etki

Eski tokenın kalan ömrü içinde yönetici uçlarına yeniden erişilebilir. Mevcut yapılandırmada access token ömrü 15 dakika. Parola sıfırlama ve refresh tekrar kullanımında da yalnız refresh tokenlar iptal ediliyor; “tüm oturumlar kapandı” mesajı access oturumlarını kapsamıyor.

Düzeltme

DB’de kalıcı SecurityVersion/security stamp tut; rol, parola ve hassas hesap değişiminde artır. JWT’ye sürüm koy ve doğrulamada karşılaştır. Yeni giriş yalnız yeni sürümle token üretsin.

Doğrulama: İki yöneticiyle rol kaldır → Customer olarak giriş → eski Admin JWT ile admin isteği. Ayrıca parola reset ve refresh replay sonrası eski access tokenın reddedildiğini doğrula.
